# QR Code Component

## Overview

This is a simple QR code component built as a Frontend Mentor challenge solution. The project displays a QR code card with accompanying text in a centered layout. It's a static HTML/CSS project focused on implementing responsive design principles and modern CSS techniques including Flexbox for layout and custom CSS properties for styling.

## User Preferences

Preferred communication style: Simple, everyday language.

## System Architecture

### Frontend Architecture
- **Static HTML/CSS Structure**: Single-page application using semantic HTML5 markup with a clean, component-based CSS architecture
- **Responsive Design**: Mobile-first approach using Flexbox for centering and layout management
- **Typography System**: Google Fonts integration (Outfit font family) with consistent weight usage (400, 700)
- **Color System**: HSL color values for consistent theming with a light background and white card design

### Styling Architecture
- **CSS Reset**: Universal box-sizing and margin/padding reset for consistent cross-browser rendering
- **Component-Based CSS**: Modular CSS classes (.qr-card, .qr-image, .card-content) for maintainable styling
- **Flexbox Layout**: Centered container using flexbox for both horizontal and vertical alignment
- **Shadow and Border Radius**: Subtle box-shadow and consistent border-radius values for modern card design

### Asset Management
- **Image Optimization**: Pre-optimized image assets stored in local images folder
- **Favicon Integration**: Standard 32x32 PNG favicon implementation
- **Responsive Images**: Images sized to 100% width with automatic height adjustment

## External Dependencies

### Fonts
- **Google Fonts API**: Outfit font family loaded via CDN with display=swap optimization

### Challenge Resources
- **Frontend Mentor**: Original challenge source providing design specifications and assets
- **Design System**: Follows Frontend Mentor's provided color palette and typography guidelines (White: hsl(0,0%,100%), Slate colors for backgrounds)

### Development Tools
- No build tools or frameworks required - pure HTML/CSS implementation
- Compatible with standard web deployment platforms (GitHub Pages, Netlify, Vercel)
